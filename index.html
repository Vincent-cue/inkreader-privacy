隐私政策

墨痕阅读器 (InkReader) · 生效日期：2026-09-22
Privacy Policy — InkReader — Effective: 2026-09-22
核心承诺：墨痕阅读器是一款完全本地运行的电子书阅读器。我们不收集、不上传、不分享任何个人信息。您的书籍、摘录与笔记仅存储在您自己的设备上。
Core commitment: InkReader is a fully local e-book reader. We do not collect, upload, or share any personal information. Your books, highlights, and notes are stored only on your own device.

一、我们收集的信息

我们不收集任何个人信息。墨痕阅读器在您的设备上离线运行，不要求登录账号，不向任何服务器发送您的使用数据。

1. Information We Collect

We collect no personal information. InkReader runs offline on your device. It does not require an account and sends no usage data to any server.

二、数据存储位置

以下数据仅保存在您的设备本地存储中，不会被我们或任何第三方获取：

  • 您导入的电子书文件（EPUB / TXT）
  • 您的划线、书签、想法笔记与截图摘录
  • 应用设置（如主题、字体偏好）

当您使用「导出 Markdown」功能时，文件会写入您主动授权的文件夹（通过 Android 系统文件选择器 SAF），我们不会读取或上传该文件夹的其他内容。

2. Where Data Is Stored

The following data is stored only on your device's local storage and is never accessed by us or any third party:

  • Imported e-book files (EPUB / TXT)
  • Your highlights, bookmarks, notes, and captured excerpts
  • App settings (theme, font preferences, etc.)

When you use "Export Markdown", files are written to a folder you explicitly authorize via the Android Storage Access Framework (SAF). We do not read or upload other content from that folder.

三、权限说明

墨痕阅读器仅申请实现核心功能所必需的权限：

  • 存储 / 文件访问（SAF）：用于导入电子书、导出 Markdown 笔记。我们不使用「管理所有文件」权限。
  • 无网络权限：发布版本不包含任何联网功能，不会在后台传输数据。
  • 无相机权限：发布版本不包含拍照 / OCR 功能。

3. Permissions

InkReader requests only the permissions necessary for core functionality:

  • Storage / File access (SAF): to import e-books and export Markdown notes. We do not use "All files access".
  • No internet permission: the release build has no networking capability and transmits no data in the background.
  • No camera permission: the release build does not include camera / OCR features.

四、第三方服务与 SDK

我们不集成任何会收集用户数据的第三方分析、广告或崩溃上报 SDK。应用使用开源本地组件（如 epub.js、Room、Hilt）完成阅读与存储功能，这些组件均在设备本地运行，不涉及数据传输。

4. Third-party Services and SDKs

We do not integrate any third-party analytics, advertising, or crash-reporting SDK that collects user data. The app uses open-source local components (e.g., epub.js, Room, Hilt) for reading and storage; these run entirely on-device and involve no data transmission.

五、儿童隐私

墨痕阅读器不专门面向儿童，也不主动收集任何年龄用户的个人信息。由于我们不收集任何数据，本应用不构成对未成年人个人信息的收集。

5. Children's Privacy

InkReader is not specifically directed at children and does not actively collect personal information from users of any age. Since we collect no data, the app does not constitute collection of minors' personal information.

六、政策的变更

如未来版本引入需要收集数据的功能（例如云端同步），我们将在此页面更新本政策，并在应用中以显著方式通知您。

6. Changes to This Policy

If a future version introduces features that require data collection (e.g., cloud sync), we will update this policy on this page and notify you prominently within the app.

八、数据删除

删除应用或清除应用数据将同时删除所有本地存储的书籍、摘录与笔记。您也可以通过应用的「书架」和「想法」界面逐条删除数据。

8. Data Deletion

Uninstalling the app or clearing its data will delete all locally stored books, highlights, and notes. You can also delete individual items through the app's Bookshelf and Reflections screens.
